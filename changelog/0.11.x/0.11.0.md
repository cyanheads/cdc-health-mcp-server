# 0.11.0 — 2026-11-01

## Added

- **`cdc_query_wonder` groups by `icd_chapter`, `icd_subchapter`, `cause_113`, `leading_causes`, `injury_intent`, `hispanic_origin`, and `month`** ([#74](https://github.com/cyanheads/cdc-health-mcp-server/issues/74)). Chapter and sub-chapter rows carry `cause_code`, which `cause_icd10` accepts; `cause_113` rows carry `cause_level`; `leading_causes` takes no other dimension; `month` rows are deaths only. A grouping whose worst case passes 10,000 rows is refused before any request; `year` beside `month`, or `icd_chapter` beside `icd_subchapter`, counts the coarser level as 1.
- **`cdc_query_wonder` rows carry each rate's 95% confidence interval** ([#75](https://github.com/cyanheads/cdc-health-mcp-server/issues/75)) as `crude_rate_lower` and `crude_rate_upper`, plus `age_adjusted_rate_lower` and `age_adjusted_rate_upper` when the row has `age_adjusted_rate`; `null` where CDC sent none.
- **`asset_types` input on `cdc_discover_datasets`, and `permalink`, `accessPoints`, and `parentIds` on its entries** ([#79](https://github.com/cyanheads/cdc-health-mcp-server/issues/79)). `not_queryable` on a chart or map names the dataset it is built on, and `cdc_get_dataset_schema` and `cdc://datasets/{datasetId}` return a filter's `parentId`.
- **`temporalCoverage`, `updateFrequency`, `geographicCoverage`, `citation`, `license`, and `attribution` on `cdc_get_dataset_schema` and `cdc://datasets/{datasetId}`** ([#80](https://github.com/cyanheads/cdc-health-mcp-server/issues/80)), as the publisher wrote them; absent where it recorded none.
- **Publishes the `cdc-health-guide` Agent Skill, served over MCP as `skill://cdc-health-guide/SKILL.md`.** It ships in the npm package, the Docker image, plugin installs, and the `.mcpb` bundle, and the server `instructions` point at it.

## Changed

- **`limit` sets the page** ([#76](https://github.com/cyanheads/cdc-health-mcp-server/issues/76)); the 200,000-character budget is gone. `cdc_query_dataset` clamps to 1,000 rows (was 5,000), `cdc_discover_datasets` takes up to 10,000 unclamped (was clamped to 100), and `cdc_query_wonder` returns up to 10,000 rows per call, the rest of the table when `limit` is omitted.
- **`cdc_discover_datasets` defaults `order` to `relevance` when `query` is set** ([#78](https://github.com/cyanheads/cdc-health-mcp-server/issues/78)) and to `dataset_id` otherwise; a relevance page with matches remaining carries a notice that offset paging can repeat or skip entries.
- **`analyze_health_trend` routes leading-cause, Hispanic-origin, and month questions to `cdc_query_wonder`**, compares its rates by their intervals, and reads `updateFrequency` and `temporalCoverage` for dataset currency.
- **`@cyanheads/mcp-ts-core` 0.13.15 → 0.13.18** brings the synced framework skills and `devcheck`, `lint:packaging`, and `clean-mcpb` scripts, the Agent Plugins `plugin.json` and `mcp.json`, and a `CDC_APP_TOKEN` setting in the plugin manifests. Error and trailer text in `content[]` is Markdown-escaped, trailer echo values render as code spans, and the `.mcpb` bundle keeps the MCP SDK's `dist/ext/skills/` runtime.

## Fixed

- **Socrata failures surface as the retryable `upstream_error`** ([#71](https://github.com/cyanheads/cdc-health-mcp-server/issues/71)): an unreachable host, a cut-off body, a non-JSON 200, and a 200 in an unrecognized shape no longer escape unclassified or read as an empty result.
- **Every CDC WONDER and Socrata request has a 20-second deadline** over its headers and body; expiry is a retryable `upstream_error`, and a stalled WONDER request no longer blocks later calls ([#71](https://github.com/cyanheads/cdc-health-mcp-server/issues/71), [#77](https://github.com/cyanheads/cdc-health-mcp-server/issues/77)).
- **The provisional database's partial year is flagged** ([#73](https://github.com/cyanheads/cdc-health-mcp-server/issues/73)): a `notice` says its latest year, and with a `month` grouping the data-through month, covers part of the period against a full-year population, and names the cutoff when a cause filter or grouping reaches causes CDC withholds for 24 weeks.
- **Empty `cdc_query_wonder` tables no longer blame suppression when CDC hid only zero-death rows** ([#81](https://github.com/cyanheads/cdc-health-mcp-server/issues/81)): the notice says no deaths were recorded, and deaths summed from `rows` read as complete.
- **`cdc_list_catalog_vocabulary` matches a `filter` under three letters or digits as a whole word** ([#82](https://github.com/cyanheads/cdc-health-mcp-server/issues/82)): `TB` reaches the tag `tb`.
- **`Unreliable` is described per database** ([#83](https://github.com/cyanheads/cdc-health-mcp-server/issues/83)): D76 and D77 flag a rate from 20 or fewer deaths; D158, D157, and D176 one whose 95% interval is wider than 160% of the rate. `category` matching is documented as case-insensitive.
- **`cdc_query_wonder` calls no longer fail with HTTP 403 under Node** ([#84](https://github.com/cyanheads/cdc-health-mcp-server/issues/84)): WONDER and Socrata requests send a `User-Agent` naming the server.
