# 0.10.0 — 2026-10-12

## Added

- **`full_description` input on `cdc_get_dataset_schema`** ([#63](https://github.com/cyanheads/cdc-health-mcp-server/issues/63)) — returns the dataset description whole. A cut description sets `descriptionTruncated` and `descriptionLength`.

## Changed

- **Dataset descriptions are capped at 4,000 characters** in `cdc_get_dataset_schema` and `cdc://datasets/{datasetId}` ([#63](https://github.com/cyanheads/cdc-health-mcp-server/issues/63)). **Breaking:** pass `full_description: true` to `cdc_get_dataset_schema` for the whole description; the resource has no opt-out. Column descriptions are never shortened.
- **A `limit` above the per-call cap is clamped and the clamp disclosed, not rejected** ([#65](https://github.com/cyanheads/cdc-health-mcp-server/issues/65)) — `cdc_query_dataset` returns at most 5,000 rows and `cdc_discover_datasets` at most 100, each with the offset to continue from. `cdc_get_dataset_schema` `column_limit`, `cdc_list_catalog_vocabulary` `tag_limit`, and `cdc_query_wonder` `limit` no longer have a ceiling. Counts in notices print with thousands separators.
- **Whitespace-only optional inputs read as omitted, as do blank tag entries and empty ICD-10 lists** ([#66](https://github.com/cyanheads/cdc-health-mcp-server/issues/66)) — `cause_icd10: []` and `mcd_icd10: []` are accepted instead of rejected.

## Fixed

- **Caller and upstream text renders as literal text in `content[]` on every tool** ([#61](https://github.com/cyanheads/cdc-health-mcp-server/issues/61)) — table cells, headings, descriptions, and notices are escaped; query echoes and field names render as code spans. `structuredContent` is unchanged.
- **`cdc_query_dataset` continuation advice stays valid for grouped and distinct queries** ([#62](https://github.com/cyanheads/cdc-health-mcp-server/issues/62)) — it keeps the caller's `order` and appends a tie-breaker the query shape admits, restarting from offset 0 when one has to be added. An ORDER BY column outside the grouping no longer advises adding it to `group`.
- **`cdc_query_wonder` rejects `NS` beside only some other age groups before sending** ([#57](https://github.com/cyanheads/cdc-health-mcp-server/issues/57)) — CDC refuses the combination.
- **An empty `cdc_query_wonder` page no longer claims no rows matched** ([#58](https://github.com/cyanheads/cdc-health-mcp-server/issues/58)) — the render shows the heading and the handler's notice names the cause.
- **`truncationCeiling` on `cdc_list_catalog_vocabulary` is scoped to the tags from `nextOffset` on** ([#59](https://github.com/cyanheads/cdc-health-mcp-server/issues/59)) — the trailer label and field description say so.
- **Relayed Socrata errors quote the caller's `limit`, not the internal over-fetch** ([#67](https://github.com/cyanheads/cdc-health-mcp-server/issues/67)).
- **Description tag stripping and truncation never cut inside a URL, email address, or surrogate pair, and prose after a stray `<` is kept** ([#68](https://github.com/cyanheads/cdc-health-mcp-server/issues/68)).
- **The WONDER XML parser scans every element in time linear in the response** ([#69](https://github.com/cyanheads/cdc-health-mcp-server/issues/69)).
