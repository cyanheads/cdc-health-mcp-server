# 0.8.7 — 2026-09-16

## Added

- **`src/index.ts` declares `sessionMode: 'stateless'`** ([#43](https://github.com/cyanheads/cdc-health-mcp-server/issues/43)) — with `MCP_SESSION_MODE` unset, the HTTP transport now resolves `stateless` from the declaration in `src/index.ts`; an exported `MCP_SESSION_MODE` value that carries a meaning still overrides it. `.env.example` and the Docker image already pinned `stateless` — unchanged here.
- **The server card publishes the resolved session mode** at `/.well-known/mcp.json` under `_meta["io.github.cyanheads.mcp-ts-core/sessionMode"]` (`"stateless"` on this server).

## Changed

- **`SIGTERM`/`SIGINT` now end the process explicitly** — exit `0` once shutdown settles, `1` if the 10s ceiling fires, instead of waiting for the event loop to drain.
- **An empty or whole-value unsubstituted `${…}` environment variable now reads as unset** — an optional `CDC_*` variable stays unset and a defaulted one takes its default.
- **The bundled framework skill tree moved from `skills/` to `framework-skills/`** — Claude Code and Codex auto-load a plugin's root `skills/`, so installing this server's plugin no longer hands its development skills to the installing agent. `.mcpbignore`, `CLAUDE.md`/`AGENTS.md`, `.github/CONTRIBUTING.md`, and `docs/tree.md` follow the path.
- **Bun engines floor raised `>=1.3.0` → `>=1.4.0`** — README badge and prerequisite line follow; the `Dockerfile` already pinned `oven/bun:1.4.0` since 0.8.6, unchanged here.
- **`cdc_query_wonder`'s advertised `outputSchema` renders the nullable `rows[].<column>` cell as `"type": ["string", "number", "null"]`** instead of an `anyOf` of the three (zod ^4.4.3 → ^4.6.4's `toJSONSchema`) — same JSON Schema meaning, not a behavior change. Every tool's `inputSchema` is byte-identical to 0.8.6.
- **Changelog moved to a per-version directory layout**: `changelog/<major.minor>.x/<version>.md` is the source of truth, `CHANGELOG.md` is a regenerated index, and `changelog:build`/`changelog:check` scripts were added; every prior entry migrated unchanged.
- Smaller items: `.env.example`'s `MCP_HTTP_HOST` comment corrected to the schema default `127.0.0.1`; README restructured (Overview → Capability reference) and gains an `MCP_SESSION_MODE` config row; `package.json` gains `audit:fix`, `start`, and the `changelog:*` scripts; `AGENTS.md` added as the byte-identical twin of `CLAUDE.md`; framework scripts and skills re-synced (`release-pr-review` 1.1 added); `.github` issue forms accept blank issues, link the private security-advisory form, and document secondary labels; plugin manifests carry `$schema`, an author email/url, and `keywords`; `manifest.json` wires `CDC_APP_TOKEN`/`MCP_LOG_LEVEL` through `user_config`; test comments now name the 0.12.4 status mapping.

## Fixed

- **A rejected tool argument now carries `structuredContent.error` with `code: -32602`** alongside the existing `isError: true` and `Invalid arguments for tool <name>: …` text — a JSON-RPC rejection, not a transport error.
- **Server identity (name, version) resolves from the served package** rather than the caller's working directory — `bunx`/`npx` runs from any directory now report `cdc-health-mcp-server` 0.8.7.
