# 0.12.0 — 2026-11-16

## Added

- **`cdc_dataframe_describe` and `cdc_dataframe_query`; `cdc_query_wonder` stages the whole table** ([#90](https://github.com/cyanheads/cdc-health-mcp-server/issues/90)). With a DataCanvas configured (`CANVAS_PROVIDER_TYPE=duckdb`), a `cdc_query_wonder` call at `offset` 0 that leaves rows past its page names the staged table in `stagedTable`; the two tools list staged tables and run one read-only SELECT over them, with no further WONDER request. Without a canvas neither tool is listed, and the `.mcpb` bundle keeps the canvas off.
- **Staged-table limits** ([#90](https://github.com/cyanheads/cdc-health-mcp-server/issues/90)). A canvas holds at most 200 staged tables, dropping the earliest-expiring first, and a table is dropped an hour after the last query that read it. `cdc_dataframe_query` counts only the rows at its `limit` toward its 1,000,000-byte reply ceiling (`result_too_large`).
- **`cdc_dataframe_query` result columns** ([#90](https://github.com/cyanheads/cdc-health-mcp-server/issues/90)). Repeated column names are suffixed (`deaths`, `deaths_1`), a column named `__proto__` fails `reserved_column_name`, and a DOUBLE NaN or infinity comes back as that string.
- **`CDC_NORMALIZE_INPUT_CASE`** (default `true`) ([#89](https://github.com/cyanheads/cdc-health-mcp-server/issues/89)). `cause_icd10` and `mcd_icd10` codes are uppercased and `datasetId` lowercased before validation; each rewrite logs an `info` line and adds to the counter `cdc.input.case_normalized`. `false` rejects the other case as before.
- **`type: "file"` entries from `cdc_discover_datasets` carry `downloadUrl` and `mimeType`** ([#88](https://github.com/cyanheads/cdc-health-mcp-server/issues/88)). `not_queryable` on a file names its name, size, and download URL.

## Changed

- **With a canvas, an omitted `cdc_query_wonder` `limit` returns 100 rows at any offset** ([#90](https://github.com/cyanheads/cdc-health-mcp-server/issues/90)), and the table is staged at offset 0. A staging failure fails the call `staging_failed`, even with an explicit `limit`. Without a canvas nothing changes.
- **The rejection text for a malformed ICD-10 code or dataset ID names the expected form** ([#89](https://github.com/cyanheads/cdc-health-mcp-server/issues/89)); the code, reason, and issue paths are unchanged.
- **`cdc_query_dataset`'s `access_denied` recovery points to `cdc_get_dataset_schema` for a file's download URL** ([#88](https://github.com/cyanheads/cdc-health-mcp-server/issues/88)).
- **Repeated prose is cut from `tools/list`** ([#91](https://github.com/cyanheads/cdc-health-mcp-server/issues/91)): `cdc_query_wonder`'s advertised prose goes from 21,544 to 15,844 bytes before the staging fields, and no other tool's prose grows apart from new fields. A guard test holds each tool to a ceiling.
- **The `cdc_discover_datasets` near-miss notice counts `(N entries)`**, where it said `(N datasets)`.
- **Socrata `invalid_query` failures render their `literals` as code spans in `content[]`, and relayed upstream error detail is cut.** A 5xx or unexpected status carries Socrata's `message` or the error page's `<title>` at up to 200 characters, and no longer the response body.
- **`@cyanheads/mcp-ts-core` 0.13.18 → 0.13.22** brings the synced framework skills, `devcheck`, `lint:mcp`, `lint:packaging`, `clean-mcpb`, and `release-github` scripts, and `changelog/template.md`.

## Fixed

- **`cdc_list_catalog_vocabulary` `filter` and the near-miss notice no longer match a value word inside a filter word past its start** ([#86](https://github.com/cyanheads/cdc-health-mcp-server/issues/86)): `international` no longer reaches `national`, nor `teenage` `age`; `vaccinations` still reaches `vaccination`.
- **`cdc_query_wonder` `content[]` heads CDC's messages `**CDC messages on this table:**`** ([#87](https://github.com/cyanheads/cdc-health-mcp-server/issues/87)), no longer as withheld rows. An empty table whose only message is the zero-deaths one gets the single "recorded no deaths" notice.
- **The `upstream_error` recovery on `cdc_get_dataset_schema`, `cdc_query_dataset`, and `cdc://datasets/{datasetId}` no longer names one host**; it reads "the Socrata portal", since a call can address either.
