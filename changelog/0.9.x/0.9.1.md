# 0.9.1 — 2026-09-22

## Fixed

- **`cdc_query_dataset`'s response budget now bounds the whole serialized result** ([#53](https://github.com/cyanheads/cdc-health-mcp-server/issues/53)) — every row reaches the caller twice, as JSON in `structuredContent` and as a table line in `content[]`; the 200,000-character budget previously charged only the JSON, letting the delivered response run to 1.5× the documented cap. Each row is now charged both costs, plus the header/empty cells a column first seen on a later row adds retroactively.
- **An empty page at `offset > 0` is diagnosed instead of blamed on filters** ([#54](https://github.com/cyanheads/cdc-health-mcp-server/issues/54)) — the handler re-runs the caller's own query at `offset: 0, limit: 1`: a row there means the offset ran past the end of a real result set, none means the query matched nothing, and a failed probe names both causes. Costs one extra request, spent only on this branch. The `content[]` empty state is now a neutral `0 rows returned` in place of the fixed spelling/filter suggestions; the cause reaches that surface through the notice, so the two cannot disagree.
