# 0.9.2 — 2026-09-22

## Added

- **`cause_icd10`/`mcd_icd10` accept a list of ICD-10 codes or ranges** ([#48](https://github.com/cyanheads/cdc-health-mcp-server/issues/48)) — matched as a union, so a code-set definition such as CDC's 16-code drug-overdose definition sends as one series with one set of rates instead of one call per code. Up to 50 entries per field; a bare string still works.
- **`cdc_query_wonder` bounds every response to the same 200,000-character budget `cdc_query_dataset` uses** ([#49](https://github.com/cyanheads/cdc-health-mcp-server/issues/49)) — an omitted `limit` now takes as many rows as fit rather than the whole table (a four-dimension grouping ran to ~480,000 characters); a budget cut discloses `truncated`, `shown`, and `nextOffset` the same way an explicit `limit` does.

## Fixed

- **Caveat and message links keep their destinations** ([#40](https://github.com/cyanheads/cdc-health-mcp-server/issues/40)) — anchors convert to Markdown links on the raw WONDER markup before tags are stripped; a fragment-only or unparseable href keeps its text with no link.
- **Concurrent `cdc_query_wonder` calls no longer race the rate-limit gate** ([#47](https://github.com/cyanheads/cdc-health-mcp-server/issues/47)) — calls now queue through one process-wide lane and go out one at a time instead of reading the same stamp and firing together, which drew a 429 on all but one.
- **A reversed `year_range` or a repeated `group_by` dimension now fails `invalid_query` before any request** ([#41](https://github.com/cyanheads/cdc-health-mcp-server/issues/41)) — a reversed range previously failed schema parsing as `invalid_arguments`, and a repeated dimension spent a rate-limited WONDER request before being rejected upstream; a repeated `age_groups` value is now deduplicated rather than silently keeping an age-adjusted rate one group cannot support.
- **`group_by`'s race-grouping wording corrected to six categories** ([#42](https://github.com/cyanheads/cdc-health-mcp-server/issues/42)) — the single-race vocabulary is six categories including "More than one race", not six plus a seventh.
- **`cdc_query_dataset`'s offset-past-end notice pluralizes correctly** — "the result set holds 1 row or fewer" instead of "1 rows".
